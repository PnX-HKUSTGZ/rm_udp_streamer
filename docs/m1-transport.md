# M1：工程骨架与协议核心

验证提交：`9136f52`，2026-11-15。Windows 与 WSL Ubuntu 使用独立检出和原生构建。此阶段只有协议接收与状态界面，尚不提供视频解码/呈现。

正式模块为无引擎依赖的 `ProtocolCore` / `UdpReceiver`、`RmVideoSession` GDExtension 与 C# 会话封装。8 字节大端头、固定 1392 分片布局、严格包长/总长/序号检查、冲突废弃、来源锁定、16 位回绕排序、共享截止时间与队列预算已实现。没有后续网络包时也由独立接收循环清理超时；取消不受连续输入阻塞。

默认预算：单组 8 MiB、8 个未完成组/32 MiB、输出 4 组/16 MiB、50 ms 组帧至消费总预算、64 组排序窗口、5 ms 首次排序窗口。压缩数据丢弃通过不连续标记传给下一消费者。跨会话代际递增，闲置重启会重建来源和序号基准。
