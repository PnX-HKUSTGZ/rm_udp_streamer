## 实现与工程收益

- `native/src/media/session.cpp:167` 的独立准备线程在锁内交换最新 FrameLease，昂贵回读/转换在锁外完成；解码线程保持顺序喂包。一个等待帧加一个正在准备帧限制 CPU 硬件引用。已有准备结果未消费时暂停继续准备，从昂贵工作前丢弃旧帧。
- `session.cpp:139`、`:154` 的失效路径同时使用 epoch 与 stream/resource/presentation 三代际；过期准备和过期错误不能重新发布，Faulted 不被正常停止覆盖。准备线程由解码线程创建/汇合，引用帧保留硬件上下文，恢复时不悬空。双平台 pipeline-v6 的九项慢准备/失效/异常/终态记录可支撑这些边界。
- `native/src/media/cpu_preparer.cpp:30` 输出池只在 use_count==1 时复用，最多三份；硬件回读按分配布局/像素格式重建，RGBA 转换缓存含色度位置，每次设置颜色矩阵/range。裁剪使用独立 AVFrame 视图，避免破坏缓存布局。没有把回读或转色放入 UI/渲染线程。
- `native/src/godot/cpu_upload_buffers.hpp:20` 限制三个平面，ptrw 写时复制保护仍持有旧数据的 Image/渲染消费者；`video_surface.cpp:65` 按布局变化清理纹理及缓存。仍然 memcpy 和创建 Image；地址变更统计不是所有分配次数，也不是零复制声明。
- `native/src/godot/video_surface.cpp:39` 在渲染队列处理上传，在执行前后核对活动状态与代际；clear 先清 canvas/material 后释放显示引用，并在同一渲染队列排退役。`cuda_gl_bridge.cpp` 保留私有互操作纹理和 Godot 采样纹理分离、CUDA producer event 与 GL consumer fence；失败隔离保留在途资源且阻止重启。
- `scripts/ui/Main.cs:185` 截图等待有真实时间两秒截止，`:207` 无截图不等待绘制，停止阶段检查失败终态/五秒截止；播放计时使用 Stopwatch。工程记录保留 TimeScale 旧失败及修复后结果、无绘制/最小化/正常截图情形。

原始工程 result 的独立读取确认同二进制 cadence 对照 53.8→60 fps、P95 43→35 ms；不同上传候选身份均保留，有效 before 上传 P95 1.9 ms、两次 after 均1.0 ms。首个与清理重叠的 before 不参与性能推断。异步准备/缓冲工程短测与当前长测没有被混成 CPU 因果比较。更高主循环频率的 CPU/功耗成本及仍存在的复制/分配已明确。

## 生命周期、故障与真实性

独立逐轮读取 Windows 原版/逐轮写盘、AMD 原版/逐轮写盘四份详细生命周期记录，各60轮；每轮1080p、720p均≥30实际新提交与主线程接受且有绘制，格式代际前进，停止终态和所有 pending 字段归零。实际 GPU 路径均有非零 copy，并检查 source release、consumer fence、retired 与 copy 守恒及资源字段存在且为零。最大停止分别49/42/17/17 ms。核对探针源码的 clear/free、重复停止与端口重绑，写盘补丁只改变详细记录保留方式，没有削减帧数、断言或期限。这是精确发行原生库的专用编辑器场景，不是60轮发行 GUI 按钮。

六项当前源码外部故障副本的原始终态已读取：event/fence/timeout 分别13.7098/29.3634/2003.0725 ms，均 stop_failed、非零退出、同/新 GPU 会话拒绝重启，退役失败且资源仍被保护；三项可选计时故障正常停止。两份故障副本原始来源清单与冻结提交逐文件核对，Windows 文本换行 CRLF 转换单独记录，不宣称故障库等于发行库。应用核心30个输入文件与既有插桩提交逐字节相同；该 ASan/UBSan 范围不含第三方库、驱动、Godot或发行二进制。

四份 AMD 完整归档摘要和提取记录逐成员字节一致；14份产品收据与工作区原件、Git blob、索引大小/SHA256一致。Windows实际原包 manifest/DLL 重新计算符合记录。三条正式/全部ABBA的实际原生库与程序集身份保存在独立收据。旧/新 Windows DLL 归一化后未解释的40字节代码差异不用于等价推断，结论依据新库实测。

## 结论边界

通过范围是上述三条已测1080p60、8位SDR固定HEVC样本路径及本阶段相关实现/回归。RGBA、CUDA/CPU、WSL软件呈现及其他未经正式长测组合不获得相同性能等级。AMD Mutter PowerSaveMode 0/3 限制仍保留；模式/可绘制/未锁屏不证明物理扫描，延迟终点为纹理提交。恢复应继续把上游关键帧等待与原生首片到提交分开，不跨时钟域相减。
