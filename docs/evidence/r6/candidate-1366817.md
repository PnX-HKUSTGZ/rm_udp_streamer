## 已保留的失败与边界

旧 `2e340dc` 的 Windows D3D11VA 第 51 轮停止误报故障原件保留，确定性对照证明修复前失败、修复后正常停止，真实上传错误仍可观察。旧桌面非法设备用例没有输入视频，因此延迟打开解码器的程序正确停在等待参数；本轮补齐有效输入，保留旧测试失败，没有改写为通过。

本候选第一次 Windows CUDA 10/60 秒工程预检未达到既定帧率门槛：均值 57.2667 fps、完整秒窗 P10=55，首包到提交 P95/P99 为 33/40 ms，退出正常。测量区有 3 个超时缺组和 4 次恢复；发送单帧分片最长 65.6132 ms，超过接收器原有 50 ms 组装期限。失败后观测到后台编辑器索引活动，但未取得其在测量期间的因果证据。该结果保留，不降低门槛，不据此声明正式 1080p60 通过。

两台 Ubuntu 现已完成正式长测和完整诊断对照；Windows 一次事前声明的 v2 复核短测通过，正式长测仍未达到帧率门槛，后续 Windows 性能步骤自动停止。完整通过、失败、资源分窗和归档见[性能记录](candidate-1366817-performance.md)。旧候选的正式性能不继承到本候选。原生 Ubuntu NVIDIA、Windows AMD 仍缺实机；R4/R6 尚未完成，也未提交阶段完成审查。
